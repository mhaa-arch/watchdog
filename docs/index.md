# Watchdog Core guide

A requested watchdog period is nominal. The actual expiry and any service window depend on the target clock and configuration.

Read the period and service-window rules before arming the watchdog.

- [Run the example](examples.md) to see the same API with a simulated resource.
- [Check portability](compatibility.md) for assumptions that belong to the target.
